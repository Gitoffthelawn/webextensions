Download a link, an image or a video with a single right click. No questions, no dialog, no extra steps.

**Quick start**

1. Right click a link, an image or a video.
2. Choose "Just Download".
3. The file is saved to your downloads folder right away.

**What gets downloaded**

- **A link**: the file or page the link points to.
- **An image or a video**: the picture or the video file of that element. If an image is part of a link, the image is downloaded and not the link target.

The file is saved with the name that Firefox picks from the address or from the answer of the website. If a file with that name already exists, a number is added to the new one, so nothing is overwritten. The download uses your normal browser session, so it works for files that need you to be logged in.

**Good to know**

- Only web addresses (http and https) can be downloaded. Videos that a page plays from a temporary internal address (a "blob" address), as many streaming sites do, cannot be downloaded this way.
- There is no toolbar button and there are no settings. Everything is in the right click menu.
- You can watch and open your downloads in the Firefox downloads panel, as for any other download.

**Notification (optional)**

If you click "Just Download" on something that cannot be downloaded, the add-on can tell you with a short "Invalid URL" notification. This needs the optional permission to show notifications. It is not requested automatically. To allow it, open the Add-ons Manager, select this add-on and switch on the notifications permission on the Permissions tab.

**Permissions and privacy**

- menus: add "Just Download" to the right click menu.
- downloads: save the files.
- notifications (optional): show the "Invalid URL" message.

The add-on does not collect or transmit any data. It only asks for the file that you chose to download.
