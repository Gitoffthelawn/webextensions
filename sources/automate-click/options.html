Step 1 of 4 — Which website?

A rule watches for a website address and then clicks something on it automatically. Paste the address of the page you want to automate below.

Step 2 of 4 — What should be clicked?

To click something automatically (like a "Close" or "Accept" button), Automate Click needs a CSS selector — a short code that points at that exact element on the page.

  1. Open the website in another tab and find the thing you want clicked.
  2. Right-click directly on it and choose Inspect (or Inspect Element).
  3. The Developer Tools panel opens with that element highlighted in the code.
  4. Right-click the highlighted line of code, then choose Copy → CSS Selector.
  5. Come back to this tab and paste it below.

Tip: switch to the tab with the actual website open, then come back here and press "Test" — the matching element will briefly flash orange on the page so you can confirm it found the right thing.
