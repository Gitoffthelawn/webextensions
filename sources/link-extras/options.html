    Copy formats

    Each row adds an entry to Copy Links as…. Tick HTML to also copy the result as an HTML fragment (text and URLs are escaped). Row 1 is used by shortcut “format 1”, row 2 by “format 2”, and so on.

    • %url full URL
    • %url_origin scheme + host + port
    • %url_proto protocol, e.g. https:
    • %url_host host name
    • %url_port port
    • %url_path path
    • %url_params query string
    • %text link text
    • %nl new line
