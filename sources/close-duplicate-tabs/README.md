Adds a toolbar button that shows the number of duplicate tabs and when clicked will close the duplicates  (left to right)

# DEMO

https://github.com/user-attachments/assets/31af7225-d5f0-4a8e-842c-1b0a805864a9

# REQUIRED PERMISSIONS

- tabs: used to read tab urls to compare tabs and hook into tab loading events to update the duplicate counter 
- cookies: used to read tabs containerId (aka. cookieStoreId) property to compare tabs
