How scripts work
  • The code is the body of a function and must return true for every tab that should be selected.
  • cmpTab is the tab being tested, clkTab is the reference tab shown in the selector window (the tab that was active when you opened it). Both have the usual tab properties (url, title, pinned, lastAccessed, cookieStoreId, ...).
  • The code runs inside the page of cmpTab, so document and window are available. Tabs where scripts are not allowed (about: pages, addons.mozilla.org) never match.
  • Click the toolbar button to open the selector window. A filter first shows a preview of the tabs it would select; Apply then selects them. Every group is a button there; it previews the tabs that match all enabled scripts of that group. The Scripts… button in that window opens this page.
  • Only enabled scripts are ever executed. The UserScripts keyboard shortcut (set it on the add-on shortcuts page of Firefox) selects the tabs that match the enabled scripts of every group at once, which must all match (AND). Import examples.json for ready-made samples.
