👋 Welcome, and thanks for installing!

Tabs opened in the background (middle-click, "open in new tab", links from other apps) are now held back and only load once you switch to them. Here is how to get started:

  1. Choose a mode below.
  2. Add URL patterns (regular expressions), one per line.
  3. Use the toolbar button to pause or resume the extension at any time.

Heads up: the default is Whitelist mode with an empty list, which holds back every background tab. Add patterns for sites that should always load, or switch to Blacklist mode to hold back only specific sites.
