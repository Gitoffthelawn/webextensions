Copy Video Frame

How to use
1

Hold Shift and right-click a video

This bypasses the page's own player menu so Firefox's normal context menu — and "Copy Video Frame" in it — shows up.

2

Click "Copy Video Frame"

The current frame is captured. If clipboard access has been granted, it's copied straight to your clipboard.

3

No clipboard access yet?

The frame opens in a small popup window instead, where you can right-click the image to copy or save it.

Protected (DRM) videos Some streaming sites block direct frame capture. For those, the addon falls back to capturing the visible area of the tab instead — it'll still work, just via a slightly different path.
Keyboard shortcut Press Alt+Shift+V to capture whichever video the mouse is over — no need to open the context menu. If nothing's hovered, it captures the first playing video on the page instead. Change the key combo any time in Firefox's about:addons → gear icon → "Manage Extension Shortcuts".
Toolbar button Click the extension's toolbar icon to capture the first video currently visible in the tab — handy when you'd rather not hover the video or use the keyboard shortcut.
Shutter sound
Current sound: default

Capture method

Normally, frames are read directly from the video, which is sharper but skips anything drawn on top of it — subtitles, captions, or a custom player's on-screen overlays. Turning this on always uses the same screenshot-based method the addon already falls back to for DRM-protected videos, which captures everything visible on screen — subtitles included. The video needs to actually be on screen (not scrolled out of view) for this to work.
