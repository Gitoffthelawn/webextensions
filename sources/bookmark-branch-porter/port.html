Bookmark Branch Porter

Import or export a branch of your bookmark tree as JSON or HTML

    What would you like to do?

    Export copies a branch of your bookmarks out as text or a file. Import adds bookmarks from a file or from pasted text.

    Which part of your bookmarks?

    Choose a folder to export with all its subfolders, or export the entire tree.

    Which format?

    JSON keeps the folder structure as data. HTML is the standard bookmarks file that most browsers can import.

    Provide your data

    Open a JSON or HTML file, or paste the data into the box below.

    Data to import
    Format (detected automatically, change it if it is wrong)

    Where should the bookmarks go?

    Imported bookmarks are added to the folder you choose. Existing bookmarks are not replaced or removed. The root of the bookmark tree can't be an import target.
