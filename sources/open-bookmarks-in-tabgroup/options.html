Open Bookmarks in Tabgroup

Options

Welcome! Choose how bookmark folders open as tab groups below.

The tab group's color is derived automatically from the bookmark folder's name — the same folder name always gets the same color.

Replace an existing tab group

If a tab group with the folder's name already exists, close it and reopen it fresh. Turn off to keep it and only add bookmarks whose URLs aren't already open in that group.

Collapse the tab group

Start each new tab group collapsed instead of expanded.

Load tabs immediately

Turn off to open tabs unloaded — they only load once clicked, which is faster for large folders.

Changes are saved automatically.
