Adds a toolbar button to find RSS, ATOM and JSON feeds
Click the toolbar button to start the detection of page related feed-like assets. 
The addon has a basic set of detection functions to find potential feed urls, that can also be further customized by the user. The options page lists all detector rules (site URL regex + JS code that returns candidate feed URLs for that site). You can edit, add, or delete rules there, and use Import/Export to save or share your rule set as JSON.
